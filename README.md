# 🍦 Treinando Meu Primeiro Modelo de Machine Learning para Prever Vendas

Este repositório contém a resolução do desafio de projeto do curso **DP-100 da Microsoft na plataforma DIO**. O objetivo é criar um modelo preditivo para a sorveteria "Gelato Mágico".

## 📋 Cenário e Objetivo
O desafio consiste em prever a quantidade de sorvetes vendidos com base na temperatura ambiente. Utilizei o conceito de **Regressão Linear** para criar uma linha de tendência que ajuda o negócio a planejar seu estoque de forma inteligente.

## 🛠️ Tecnologias Utilizadas
* **Python**: Para a construção da lógica.
* **Scikit-Learn**: Para o treinamento do modelo de Machine Learning.
* **Pandas**: Para organização dos dados de temperatura e vendas.
* **Matplotlib**: Para visualização gráfica dos resultados.

## 🧠 Racional do Projeto (Passo a Passo)
1. **Coleta de Dados**: Definição de uma base histórica relacionando graus Celsius e unidades vendidas.
2. **Treinamento**: O modelo analisou os dados e aprendeu a correlação entre as variáveis.
3. **Previsão**: Realizei um teste prático onde, para uma temperatura de **32°C**, o modelo previu a venda de **125 sorvetes**.
4. **Visualização**: Gerei um gráfico de dispersão com a linha de regressão para validar o aprendizado da máquina.
